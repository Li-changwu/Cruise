# Bound control-substrate experiments

P0 first tests the supported CANN DataFlow/FlowFunc, n-mapping, partial-feed,
and control-queue path. If it cannot satisfy the Persistent Control Spike, one
additional officially supported Device-resident control substrate may be tested
without relaxing any invariant. Failure of both records the current CANN 9 and
Ascend 910B2 stack as architecturally infeasible for the Persistent Device Model
Owner and stops this direction; the Epoch Reference Scaffold is not promoted as
a fallback product architecture.
