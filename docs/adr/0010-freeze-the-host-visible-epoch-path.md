# Freeze the Host-visible epoch path

The fixed-K Host-Visible Decode Epoch implementation is frozen as the Epoch
Reference Scaffold. It may be used as a correctness oracle, measurement
reference, model bring-up aid, or to reduce a concrete risk in the Persistent
architecture, but it will receive no independent product feature work and is
not a fallback release path. Its correctness or performance cannot complete a
Persistent Device Model Owner milestone.
