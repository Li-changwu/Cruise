# Historical Source Snapshots

`attempts/` contains source-only snapshots from the research workspace before
the active Attempt 74 implementation. Generated binaries, models, caches,
logs, profiler output, and raw result trees were excluded from the import.

These directories preserve failed experiments and superseded implementations
because they record why later design choices exist. They are not independently
maintained packages, and the repository test suite targets the active root.
See `docs/PROJECT_HISTORY.md` for the milestone map.
