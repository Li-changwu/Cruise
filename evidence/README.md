# Evidence Policy

This directory is reserved for compact, reviewable evidence such as result
summaries, verifier output, source manifests, and hashes. Raw profiling trees,
AIR packages, weights, runtime logs, arrays, and scratch output are not stored
in Git.

The current accepted measurements are summarized in the frozen historical
status documents. Original large artifacts remain outside this repository and
must be matched through their recorded SHA-256 values before use in a paper.
