Status: passed on 2026-07-31. This is the EngineCore exit gate for the
narrow M1 support contract; it is not a soak or performance qualification.

- Model and tokenizer: the pre-existing frozen Qwen2.5-7B-Instruct asset at
  `/dev/shm/cruise-m0-assets-npu01-r1/model-frozen`
- CANN/vLLM and vLLM-Ascend identities are recorded in the compact evidence

No model was downloaded, moved, or duplicated. Build, deploy, sockets, logs,
and mutable GraphPp weights were confined to marker-owned `/dev/shm` scratch.

## Workload and Result

The same deterministic workload contained exactly 1,000 requests in 400
cohorts. It covered B=1,2,3,4 (100 cohorts each), prompt lengths 2,3,4,5
(250 requests each), output budgets 2-7, 800 eligible requests, 50
`eos_second_token`, 50 `cancel_after_prefill`, 50 `cancel_after_device`, and
50 `unsupported_min_tokens` requests. Baseline and Cruise matched all request
outputs, terminal state, finish/stop reasons, and scheduler accounting.

Cruise aggregate counters were:

|---|---:|
| Device model steps | 809 |
| Host model steps | 546 |
| Device-routed requests | 844 |

| Generation-checked row reuses | 840 |
| Device-owned cancellations | 24 |
| Device EOS short epochs | 16 |
| KV checksum mismatches | 0 |
| Host/device-owned violations | 0 |

The unsupported requests stayed on the Host path. The comparison result is
`pass=true` with no mismatches.
